# One Word, One Username, One Reward

One word (15 characters, limit 30): the entrant's own make.fun username, and nothing else.

> jolly-meteor-97

`main.py` (Python 3.13, stdlib only) writes that word to `/output/entry.txt`. Deterministic: the same text on every run.
